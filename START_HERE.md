# RF Measurement Analyzer — начни здесь

Проект лежит в `~/Projects/rf-measurement-analyzer`.

## Запуск

1. Открой эту папку целиком в VS Code.
2. В Finder дважды нажми `start.command` либо в терминале VS Code выполни:

```bash
.venv/bin/python run.py
```

3. Открой **http://127.0.0.1:8003/**. Пока пользуешься приложением, терминал должен оставаться открытым.

Если сервер уже запущен, достаточно открыть ссылку. Ошибка «Address already in use»
означает, что порт занят; сначала проверь существующую вкладку. Предыдущий Virtual Test
Bench использует порт 8001, новый анализатор — 8003.

## Что смотреть

Сразу загружены два искусственных `.s2p`:

- **A / filter-nominal.s2p:** фильтр с центром 2,45 ГГц; PASS.
- **B / filter-degraded.s2p:** центр смещён к 2,54 ГГц, потери выросли; FAIL, три нарушения.

Нажми на карточку A или B. Таблица покажет требования выбранного образца,
худшую частоту и запас до допуска. Отрицательный запас означает нарушение.
График передачи сравнивает оба файла; согласование и все S-параметры относятся
к выбранному образцу. Зелёная область — требуемая полоса пропускания.

Слева можно менять требования. После изменения нажми **Проверить требования**.
Без этого таблица относится к предыдущим условиям, а экспорт отчёта недоступен.

Вверху **HTML-отчёт**: самостоятельный файл с графиком, условиями и результатами.
Внизу **CSV**: все исходные частотные точки в численном виде.

## Откуда взялись файлы

Это результат расчёта идеальной LC-цепи с сопротивлениями потерь, а не случайные кривые.
Схема: последовательный LC → параллельный LC → последовательный LC.
Для проблемного образца изменены резонанс и потери. Оба файла пассивны и взаимны.

Данные и компоненты находятся в `examples/`. Скачать `.s2p` можно прямо из интерфейса.
Настоящих измерений анализатора цепей здесь нет; все демо-файлы явно помечены синтетическими.

## Свой файл

Нажми **Загрузить .s2p** у A или B. Поддерживается Touchstone 1.0, S-параметры RI/MA/DB,
одно реальное опорное сопротивление обоих портов, до 2 МиБ и 20 000 точек.
Для сравнения у файлов должно совпадать опорное сопротивление. Файл можно анализировать
отдельно: убери B кнопкой ×. Загрузки исчезают после перезапуска сервера.

Если диапазон не покрывает требования, получишь **НЕПОЛНЫЕ ДАННЫЕ**, а не ложный PASS.
Файлы Touchstone 2.x, шумовые блоки и другие неподдерживаемые форматы отклоняются с объяснением.

## Где код

- `app/circuit.py` — модель фильтра и генерация `.s2p`.
- `app/touchstone.py` — чтение комплексных S-параметров.
- `app/analysis.py` — расчёты и требования.
- `app/main.py` — локальный сервер и API.
- `app/static/` — интерфейс и графики.
- `tests/` — проверки математики, чтения файлов и API.

Подробности модели и ограничения — в README.md.
